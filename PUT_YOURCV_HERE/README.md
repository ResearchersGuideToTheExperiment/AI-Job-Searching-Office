# Put your CV here

Place your PDF or DOCX CV directly in this folder, then open the dashboard.
Go to **My Profile → Original CV and supporting materials**, select **Extract / retry**, review the facts, and select **Confirm all reviewed information**.

Alternatively, upload your CV through **My Profile** from any folder.

Use a text-based PDF or DOCX, up to 10 MB. Scanned PDFs need external OCR. Originals are preserved; importing a file does not automatically confirm its facts.

This README is public. Other files in this folder are ignored by Git and rejected by the release exporter. Do not put personal details in this README.
