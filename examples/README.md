# Personal setup templates

These templates contain placeholders and are not loaded by the app automatically.

Prefer entering preferences through **My Profile**. If you want file-based preferences instead, create the ignored `PUT_YOUR_AI_MODEL_HERE/AI_instructions/` directory and copy the two Markdown templates there as `job_preferences.md` and `writing_style.md`. Replace all placeholders with your own choices before launching.

`autonomous.example.json` illustrates the office configuration format. Its example source is deliberately disabled. Configure real sources in the dashboard; do not treat example.org as a job board.

Never edit public examples to contain your real CV, contact details, work history, or personal preferences.
